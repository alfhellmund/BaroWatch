진단 데이터 보내기

기술적인 문제가 있을 때는 진단 파일이 도움이 됩니다. iPhone 또는 iPad 앱에서 톱니바퀴 아이콘(설정)을 탭한 다음 진단 섹션에서 진단 데이터 보내기를 탭하십시오. 공유 시트가 열리면 파일을 보낼 곳을 직접 선택합니다. 파일에는 좌표와 페어링 코드가 포함되지 않습니다. 자세한 내용은 개인정보 처리방침에 있습니다.

자주 묻는 질문

iPhone에 기압이 표시되지 않는 이유는 무엇입니까?

모든 기기에 기압 센서가 있는 것은 아닙니다. 센서가 없으면 앱은 페어링된 iPad나 Apple Watch에서 전송된 측정값을 표시합니다. 센서가 있는데도 값이 표시되지 않으면 설정 → 개인정보 보호 및 보안 → 동작 및 피트니스에서 ‘피트니스 추적’과 BaroWatch 앱이 켜져 있는지 확인하십시오.

QFE와 QNH의 차이는 무엇입니까?

QFE는 현재 위치에서 측정한 현지 기압입니다. QNH는 해면 기압으로 환산한 값이므로 일기 예보와 비교할 수 있고 현재 고도와 관계가 없습니다. 환산에는 GPS 고도 또는 사용자가 입력한 고정 고도가 사용되며, 추정 고도에는 ‘≈’ 표시가 붙습니다.

iPhone과 iPad는 어떻게 페어링합니까?

두 기기가 같은 네트워크에 있거나 Bluetooth 범위 안에 있어야 합니다. 설정 → 기기 페어링에서 각 기기에 6자리 동기화 코드가 표시됩니다. 한 기기의 코드를 다른 기기에 입력하고 ‘적용’을 탭하십시오.

Apple Watch에 iPhone과 다른 기압 값이 표시되는 이유는 무엇입니까?

표시 방식(QFE 또는 QNH)은 기기마다 따로 설정합니다. 서로 다르게 설정되어 있거나 기기들이 서로 다른 고도로 계산하면 값이 달라집니다. 작은 차이는 센서의 위치(손목 또는 바지 주머니)에 의해서도 생깁니다.
